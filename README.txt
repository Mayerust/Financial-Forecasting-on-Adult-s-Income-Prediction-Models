## 🚀 Project Overview

This ML-powered project predicts income brackets (≤$50k or >$50k) based on demographic/occupational data to enable smarter financial planning.

### 🔍 Highlights
- AdaBoost model training
- Flask-based web deployment for real-time predictions
- Business scenarios: investment advice, marketing targeting, and financial optimization

---

## ⚙️ Key Features

- **Data Preprocessing**: Categorical encoding, SMOTE balancing, outlier handling  
- **Model Comparison**: Logistic Regression, Decision Trees, Random Forest, AdaBoost  
- **User-Friendly Web Interface**: Interactive inputs with explanation  
- **Flask Deployment**: Modular HTML templates and joblib integration
